域名映射

添加后自动写入 hosts 并即时生效；访问 http://域名/（不带端口）即可打开目标服务。域名仅在本机解析。同时会把域名加入系统代理绕过列表（见下方「系统代理绕过」面板）。

本地 HTTPS（去掉浏览器"不安全"标识）

—
启用后自动生成本地 CA 并装入系统信任存储（无弹窗），按域名签发证书；http 地址会 308 跳转到 https。Firefox 使用独立证书库，需在其设置中手动信任 data/ca.crt。

开机自启（计划任务 LocalMapEngine）

—
任务以 SYSTEM 身份运行引擎（无窗口），注册/删除需要引擎本身具有管理员权限。

系统代理绕过（ProxyOverride）

—
开启系统代理（Clash 等）时，浏览器会把映射域名交给代理解析导致无法访问；本功能把映射域名（含 *.域名）自动写入系统代理绕过列表使其直连。引擎每次启动会自愈补回被代理软件覆盖的条目；删除映射只移除 LocalMap 自己写入的条目。

自检（模拟浏览器访问链路逐项检查）

依次检查：代理端口归属 → HTTPS 证书 → CA 信任 → hosts → 代理绕过 → 开机自启指向。
